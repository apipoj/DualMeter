# Attribution

DualMeter is a combined desk display for Claude Code and Codex usage.

Firmware, BLE protocol, and macOS daemon are based on
[Clawdmeter](https://github.com/HermannBjorgvin/Clawdmeter).

Codex quota reading uses the local Codex App Server flow from
[CodexMeter](https://github.com/tomatoeggs/CodexMeter).

Clawdmeter includes Anthropic brand fonts and Clawd artwork. See that
repository's licensing note before redistributing splash assets.
